Rebuild 初猜改进：从 env block 对角化到完整 dm 对角化

2026-06-16 08:30 (updated)

本次目标

  1. 改进 rebuild_from_embedded_density() 的 CAHF 初猜：用收敛的 embedded CAHF density（通过 Lowdin basis 投影到新 embedded space）代替从 fragment SCF density 重新构造
  2. 提取 _cahf_mo_from_density() 公共方法，消除 _embedded_cahf_initial_guess 和 rebuild 中的重复 MO 构造逻辑
  3. 诊断验证投影质量：确认完整投影密度矩阵的本征值结构
  4. 简化初猜步骤：将 rebuild 路径从 env block 对角化改为完整 dm 对角化，与 ssdmet 一致

代码改动

1. 新增 _cahf_mo_from_density() 方法

位置：embed_sim/fragment.py FDMET 类，line 690-771。

从原 _embedded_cahf_initial_guess 中提取的公共逻辑。接受任意 embedded-space density matrix，对角化环境子块得到 natural orbitals，然后按 CAHF 风格构造 [core | active | virtual] 排序的 mo_coeff / mo_occ / es_dm。

核心步骤：

  1. 通过 search_impurity_ao_label(embedded_active_aolabels) 确定 active indices（保持 active AO 在正确位置）
  2. 取 env block dm_es[np.ix_(env_idx, env_idx)] 对角化
  3. 按 occupation 降序排列，前 ncore = (nelectron - nelecas) // 2 个作为 core，其余作为 virtual
  4. 构造 mo_occ = [2,...,2, nelecas/ncas,...,nelecas/ncas, 0,...,0]
  5. 返回 mo_coeff, mo_occ, es_dm = (mo_coeff * mo_occ) @ mo_coeff.T

同时记录 es_init_guess_info（env_occ, core_occ_min, virtual_occ_max 等）供诊断使用。

2. 重构 _embedded_cahf_initial_guess()

位置：line 663-688。简化为：fragment density 拼接 → trace rescale → 委托 _cahf_mo_from_density()。原有的 env block 对角化和 MO 构造逻辑已移入公共方法。fragment_density 路径保持不变。

3. 最终版 rebuild_from_embedded_density() 初猜构造

位置：line 879-908。前半部分（环境分解 → es_orb → 积分重建）不变。初猜构造从 env block 对角化改为完整 dm 对角化（与 ssdmet build_embeded_subspace line 116 一致）：

# project converged Lowdin density into new embedded basis
U_new = cloao @ self.es_orb
dm_es_new = U_new.T.conj() @ ldm @ U_new
dm_es_new = (dm_es_new + dm_es_new.T.conj()) * 0.5

ncas = self.fragment_scf_options['ncas']
nelecas = self.fragment_scf_options['nelecas']
nelectron = self.mol.nelectron - 2 * self.nfo
ncore = (nelectron - nelecas) // 2

# diagonalize the FULL embedded density (cf. SSDMET build_embeded_subspace)
es_occ, es_nat_orb = np.linalg.eigh(dm_es_new)
es_occ = es_occ[::-1]
es_nat_orb = es_nat_orb[:, ::-1]

mo_occ = np.zeros(self.nes)
mo_occ[:ncore] = 2
mo_occ[ncore:ncore + ncas] = nelecas / ncas
es_dm = (es_nat_orb * mo_occ) @ es_nat_orb.T.conj()
es_dm = (es_dm + es_dm.T.conj()) * 0.5

self.es_init_guess_info['kind'] = 'rebuild_projected'
self.es_init_guess_info['nat_occ'] = es_occ
self.es_dm = es_dm
self.es_mf.mo_coeff = es_nat_orb
self.es_mf.mo_occ = mo_occ
self.es_mf.get_init_guess = lambda *args, **kwargs: self.es_dm

核心改进：np.linalg.eigh(dm_es_new)（完整 dm）替代 np.linalg.eigh(dm_es_new[env_block])（env block）。完整 dm 的本征值严格为 {2, f, 0}，natural orbitals 精确重建收敛密度（差一个 degenerate 子空间内的酉旋转）。

设计选择

  • 复用 ldm：rebuild 过程中已计算 Lowdin density ldm（用于环境分解），投影初猜直接复用，不需要额外的密度变换
  • FO 密度补充：ldm 中补充了外部 FO 轨道的密度贡献（fo_ldm @ fo_ldm.T * 2），FV 轨道 occupation 为 0 无贡献
  • 完整 dm 对角化 vs env block 对角化：完整 dm 对角化直接得到严格 {2, f, 0} 本征值，natural orbitals = dm 的本征向量。env block 对角化是绕远路——env 子块的本征值受 impurity-env off-diagonal 耦合影响（bath ~1.984），需强制赋值 occupation，不如直接对角化完整 dm 简洁
  • 与 ssdmet 一致：ssdmet 在 build_embeded_subspace 中对角化完整 ldm_es（line 116），rebuild 路径现在遵循同样的模式
  • 覆盖 get_init_guess：通过 self.es_mf.get_init_guess = lambda: self.es_dm 将密度直接注入 SCF 引擎

关键结论

完整 dm 对角化是正确做法

完整投影密度矩阵的本征值严格为 {2, f, 0}，对角化得到的 natural orbitals 就是 dm 的本征态。env block 对角化引入 bath 轨道的 "fake fractional" 本征值（~1.984），需要强制赋值为 2，本质上是不必要的绕路。

ssdmet 在 build_embeded_subspace 中就对完整 ldm_es 对角化（line 116），rebuild 路径现在与之保持一致。

Env block "非严格 2" 是固有特征，非投影缺陷

完整 dm 的本征值严格为 {2, f, 0}，但 env block 的本征值出现 ~1.984：

  1. CAHF 的 core 本征向量在 embedded basis 中同时跨越 impurity 和 env 指标
  2. env block 只是 dm 的子矩阵，其本征值受 off-diagonal 耦合影响
  3. 这些 "非严格 2" 的本征值就是 bath 轨道——与 impurity 有量子纠缠的环境轨道

此特征在旧 basis 和新 basis 均存在，不代表投影质量问题。

验证规范

未来对 rebuild 投影质量的验证应检查：

  • 完整 dm_es_new 本征值：应严格为 {2, f, 0}
  • 子空间重叠度：svd(U_old.T @ U_new) 的奇异值应接近 1.0
  • Trace 守恒：trace(P_new @ ldm @ P_new) = trace(ldm)

不应以 env block 本征值是否严格为 2 来判断投影质量。
