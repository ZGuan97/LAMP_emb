FragmentMolecule 封装与索引函数合并

2026-06-15 15:48

本次目标

  1. 将 _make_fragment_mol、run_fragment_scf、bath_from_ligand_density、fragment_orbitals_to_parent_orbitals 四个自由函数封装为 FragmentMolecule 类的方法
  2. 合并 _resolve_local_ao_indices 和 _resolve_impurity_embedded_indices 为一个通用 _resolve_indices
  3. 精简代码风格（减少换行、单行 raise）和清理冗余（删除 __init__ 中的 None 占位、删除冗余 int() 包装）
  4. 统一 verbose 参数命名，删除前缀

代码改动

1. FragmentMolecule 类封装

将 LigandReference dataclass 重命名为 FragmentMolecule，添加类型字段和方法：

  • FragmentMolecule.mol, .parent_atom_ids, .fragment_to_parent_idx, .fragment_imp_idx, .fragment_lig_idx, .charge, .mf — dataclass 字段
  • from_parent_mol(cls, parent_mol, impurity_atoms, ligand_atoms, ...) — classmethod 工厂，负责构建 fragment 分子、计算 AO 索引映射。替代原 _make_fragment_mol
  • run_scf(self, fragment_scf, verbose, **kwargs) — 实例方法，运行 fragment SCF/CAHF。替代原 run_fragment_scf。使用 self.mol 而非传入参数
  • build_bath(self, threshold) — 实例方法，从 fragment 密度构造 bath 轨道。替代原 bath_from_ligand_density。使用 self.mol 做 Lowdin 正交化
  • orbitals_to_parent(self, frag_orb, nao) — 实例方法，将 fragment AO 轨道投影到 parent AO 空间。替代原 fragment_orbitals_to_parent_orbitals

删除了对应的四个自由函数。

2. 索引函数合并

合并 _resolve_local_ao_indices(mol, ao_idx, name) 和 _resolve_impurity_embedded_indices(obj, ao_idx, name) 为：

def _resolve_indices(ao_idx, name, lookup):

lookup 为可调用对象，区分两种查表方式：

  • FragmentMolecule.run_scf 中用 lambda labels: gto.mole._aolabels2baslst(self.mol, labels, base=0)（parent AO 查表）
  • FDMET.build() 的 embedded CAHF 中用 self.search_impurity_ao_label（embedded 空间查表）

原两个函数共 36 行 → 合并后 18 行。

3. RDIIS 配置改进

  • rdiis.py：RDIIS.setup() 中，rdiis_imp_idx 未设置时通过 warnings.warn() 发出警告而非静默使用默认值
  • fragment.py：FDMET.build() 的 embedded CAHF 部分删除了 default_imp_idx，rdiis_imp_idx 变为必须设置

4. 命名和风格统一

  • fragment_scf_verbose → verbose（与 PySCF 一致）
  • self.ligand_refs → self.fragment_mols
  • self._make_fragment_mol → self.make_fragment_mol（去掉下划线前缀）
  • _fragment_density_to_parent_density 中 ligand_refs 参数 → fragment_mols
  • 多行表达式压缩为单行（raise、函数调用、if 语句）
  • 删除 search_impurity_ao_label 中冗余的 int() 包装（_aolabels2baslst 已返回 int）

5. __init__ 精简

删除 16 行 self.xxx = None 占位（fo_orb、fv_orb、es_orb、es_occ、nfo、nfv、nes、nbath、nappended_fo、nkept_fv、es_int1e、es_int2e、es_mf、es_dm、es_init_guess_info、fragment_mols）。这些属性全部在 build() 中赋值。

设计选择

  • FragmentMolecule 使用 @dataclass 加方法而非纯 stateless 类——保持字段清晰可读
  • from_parent_mol 作为 classmethod 工厂（而非 __init__）：遵循"__init__ 只做赋值，需推导的值放在 classmethod"原则
  • _resolve_indices 使用 lookup callable 而非继承/重载：调用方上下文差异大（parent mol vs FDMET instance），callable 注入最简洁
  • embedded CAHF 的 rdiis_imp_idx 删除了默认值：让用户显式指定 impurity 轨道范围，避免静默行为
