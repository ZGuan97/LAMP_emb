概述与动机

标准 DMET 的 bath orbital 构造依赖全局 HF/CASSCF 参考波函数。对于过渡金属和镧系配合物（特别是单离子磁体）， 全局 SCF 在大配体、大基组或低对称性体系下可能成为计算瓶颈。

Fragment-DMET 利用体系的化学分片结构，将全局 SCF 替换为一系列更小的 fragment-local SCF/CAHF 计算。 每个 fragment 由中心金属离子（impurity）和一个配体片段（ligand）组成。从每个 fragment 的局部密度矩阵中提取 bath orbitals，再合并为最终 embedded cluster space。

该方法的物理假设：

  1. 中心离子与每个配体片段的主要纠缠可通过对应的 center-ligand 局部子体系捕捉
  2. 配体间通过中心离子的间接耦合可在最终 embedded Hamiltonian 中部分恢复
  3. CAHF 参考能提供比普通 HF 更稳定、更对称的局部平均场

算法推导和公式详见 fragment.md。

核心概念

空间划分

全体系 AO 轨道空间划分为 impurity 和 environment：

\[ \mathcal{A} = \mathcal{I} \oplus \mathcal{E}, \quad \mathcal{E} = \bigoplus_f \mathcal{L}_f \]

每个 fragment 的局部计算空间为 \(\mathcal{A}_f = \mathcal{I} \oplus \mathcal{L}_f\)。

固定 Impurity 正交化

不同 fragment 的 Lowdin 正交化会产生不同的 impurity 空间，破坏 bath 合并时的一致性。 FDMET 使用 ssdmet.lowdin_orth(preserve_imp=True)，确保所有 fragment 共享同一个 impurity 定义： impurity block 通过 QR 固定，environment block 投影掉 impurity 分量后做 SVD 正交化。

Fragment 电荷

第 \(f\) 个 fragment 的总电荷 = imp_charge + ligand_charges[f]。 当前 ligand_charges 只决定局部子分子的电子数， 未作为 point charge 或 embedding potential 作用于其他 fragment。 静电势可通过 xTB（GFN-xTB）计算后作为 embedding potential 引入。

方法

from_parent_mol(parent_mol, impurity_atoms, ligand_atoms, charge=None, spin=None, verbose=None)

classmethod 工厂。从母体分子构建 fragment 子分子：

  1. 取 impurity + ligand 原子并集，验证无重叠
  2. 构建截断 gto.Mole（复用母体 basis/ECP/坐标）
  3. 通过 aoslice_by_atom() 建立 fragment AO → parent AO 的完整映射
  4. 返回 FragmentMolecule（mf=None）

run_scf(fragment_scf="rohf", verbose=3, **kwargs)

运行 fragment SCF/CAHF，结果存入 self.mf。

fragment_scf实现说明
"cahf"CAHF(mol, ncas, nelecas, spin).x2c()标准 CAHF，支持 RDIIS
"cahf-soscf"CAHF_SOSCF(mol, ...)CAHF + AVAS + SOSCF 二阶收敛
"rohf"ROHF(mol).x2c()标准 ROHF，调试路径

通用选项：max_memory、max_cycle、level_shift。

RDIIS 选项：diis="rdiis"、rdiis_prop、rdiis_imp_idx（在局部 fragment 中解析 AO label）、rdiis_power。

build_bath(threshold=1e-13)

从 fragment 密度矩阵构造 bath / fo / fv 轨道。流程：

  1. 提取 fragment-local AO density（ssdmet.mf_or_cas_make_rdm1s）
  2. 固定 impurity 的 Lowdin 正交化
  3. 对角化环境密度矩阵 \(\rho_{LL}\)，按自然占据数阈值分类：bath（\(n_{\mathrm{th}} \le n_f \le 2 - n_{\mathrm{th}}\)）、frozen-occupied（\(n_f > 2 - n_{\mathrm{th}}\)）、frozen-virtual（\(n_f < n_{\mathrm{th}}\)）
  4. 构造 embedded subspace density（imp + bath block），做自然轨道分解
  5. 返回 (bath_orb, fo_orb, fv_orb)，均为 fragment AO basis 中的系数矩阵

orbitals_to_parent(frag_orb, nao)

将 fragment AO 轨道系数嵌入到母体 AO basis，非 fragment 位置填零。返回 shape (nao, n_orb)。

Build 流程

FDMET.build(verbose=3) 是主入口，执行以下三个阶段：

阶段一：Fragment 循环

对每个 ligand fragment \(f\)：

  1. make_fragment_mol() → FragmentMolecule.from_parent_mol()
  2. frag.run_scf(fragment_scf, **scf_options)
  3. frag.build_bath(threshold)
  4. frag.orbitals_to_parent(bath_orb, nao) 和 orbitals_to_parent(fo_orb, nao)

阶段二：全局合并

  1. 拼接所有 fragment bath → raw_bath，拼接 fo → raw_fo
  2. _complete_global_orbitals(mol, imp_idx, raw_bath, raw_fo, svd_tol)： 在固定 impurity 的全局 Lowdin 基下做 QR 正交化 + 秩筛选 + null space 补全
  3. 构造 es_orb = [c_imp, bath_orb, (fo appended), (fv kept)]
当前 FO 策略：默认不构造全局 frozen occupied（fo_orb = []，nfo = 0）。 Fragment-local FO 来自多个重叠子体系，不能直接合并。embedded electron number = 全体系电子数。 若 impurity + bath 轨道数不足，代码直接报错。

阶段三：嵌入空间 Hamiltonian

  1. make_es_int1e()：投影 one-electron integrals + FO HF 贡献
  2. make_es_int2e()：投影 two-electron integrals
  3. CAHF()：构造 embedded CAHF 对象

Embedded CAHF

FDMET.CAHF(**scf_options) 构造嵌入空间的 mean-field 对象：

  • 创建 mock gto.M()，电子数 = 全体系电子数 − 2 × nfo
  • 覆写 get_hcore → es_int1e，get_ovlp → I，_eri → es_int2e
  • 使用 CAHF（fractional occupation Roothaan equations）而非 ROHF
  • RDIIS 的 rdiis_imp_idx 通过 search_impurity_ao_label() 映射为 embedded space index

初猜选项

embedded_init_guess='aufbau'（默认）

使用 es_occ（来自 embedded subspace 自然轨道分解）直接构造对角密度。与 SSDMET 行为一致。

embedded_init_guess='fragment_density'

从 fragment SCF density 构造更物理的初猜：

  1. 各 fragment CAHF 提取 AO density，通过 _fragment_density_to_parent_density() 嵌回母体 basis
  2. ligand block 和 imp-lig cross block 直接使用，imp block 在 fragment 间平均
  3. 投影到 embedded basis，trace rescale 到 embedded 电子数
  4. 用 embedded_active_aolabels 选定 active orbitals（如 "Co 3d" → 5 个 active AO）
  5. 环境 block 对角化 → 按占据数降序 → 前 ncore 个作 core，其余作 virtual
  6. 构造 mo_coeff = [core, active, vir]，mo_occ = [2,…,2, nelecas/ncas,…, 0,…,0]
注意：embedded_active_aolabels 应精确选择 ncas 个 AO。 例如 CoSH4 使用 "Co 3d"（5 个轨道），不要用 "Co.*d"（def2-TZVP 中会选到多组 d 函数）。

Rebuild：从收敛密度重建嵌入空间

FDMET.rebuild_from_embedded_density(threshold=None) 在 embedded CAHF 收敛后调用：

  1. 将收敛 embedded CAHF density 变换到全局 Lowdin basis
  2. 补充 frozen-occupied 密度（fo_ldm @ fo_ldm.T × 2）
  3. 在环境 block 做自然轨道分解，按阈值分类 bath / fo / fv
  4. _complete_global_orbitals() 正交化
  5. 重建 es_orb、es_int1e、es_int2e
  6. 将收敛 Lowdin density 投影到新 embedded basis 作为新 CAHF 初猜
  7. 返回新的 es_mf（未收敛）

Rebuild 可改善 bath orbital 质量：初始 bath 来自 fragment-local density， rebuild 后的 bath 来自收敛的 embedded CAHF density，更好地反映全局纠缠结构。

典型用法

from pyscf import gto
from embed_sim import fragment, sacasscf_mixer, siso

mol = gto.M(atom='Co; S 1 2.30; ...', basis='def2tzvp',
            spin=3, charge=-2, verbose=4)

# ── 1. 定义 FDMET ──
mydmet = fragment.FDMET(
    mol,
    imp_atoms="Co",
    imp_charge=2,
    ligand_atoms=[[1, 5], [2, 6]],      # 两个 ligand fragment
    ligand_charges=[-1, -1],
    fragment_scf='cahf',
    embedded_init_guess='fragment_density',
    embedded_active_aolabels='Co 3d',
    fragment_scf_options={
        'ncas': 5, 'nelecas': 7, 'cahf_spin': 1,
        'max_cycle': 200, 'conv_tol': 1e-9, 'level_shift': 4.0,
        'diis': 'rdiis', 'rdiis_prop': 'dS',
        'rdiis_imp_idx': ['Co.*d'], 'rdiis_power': 0.2,
    },
)

# ── 2. Build: fragment SCF → bath → merge → Hamiltonian ──
mydmet.build(verbose=4)

# ── 3. Embedded CAHF ──
mydmet.es_mf.run()

# ── 4. Rebuild from converged density ──
mydmet.rebuild_from_embedded_density()
mydmet.es_mf.run()

# ── 5. Post-DMET: SA-CASSCF + NEVPT2 + SISO ──
es_cas = sacasscf_mixer.sacasscf_mixer(
    mydmet.es_mf, ncas=5, nelec=7, statelis=[0,40,0,10])
es_cas.kernel()
total_cas = mydmet.total_cas(es_cas)
mysiso = siso.SISO('CoSH4', total_cas)
mysiso.kernel()

已知限制与待开发功能

  • Fragment 间静电作用缺失：fragment-local Hamiltonian 只来自截断的 impurity+ligand 局部分子， 其他 ligand 的核吸引势、库仑势、极化效应未进入。 可使用 xTB（GFN-xTB 半经验方法）计算 fragment 间的静电势作为 embedding potential
  • FO 轨道为空：当前 nfo=0，embedded 电子数等于全体系电子数。 后续可从全局近似 density 重新定义 FO，或只冻结明确的全局 core 轨道
  • Density fitting 未实现：density_fit() 不可用
  • 二体积分未优化：仍使用全体系二体积分全局变换，未利用 fragment-local 二体积分
  • CAHF 参数统一：所有 fragment 使用同一套 averaging scheme 参数
  • Correlation potential 未自洽：fragment reference density 未与 DMET correlation potential 迭代更新
